Token : A token is smallest part/unit of text which is generated by LLM. During Tokenization LLM converts Text into Tokens. which may include word,subwords,symbols,punctuation . token can be used for model pricing and limitations.

A token is smallest part of word in which LLM Understand and process it. It cant read words/sentences it converts to tokens and performs computation on those tokens and generates new tokens as output


Context Window : Maximum amount of tokens which can sent to LLM at one time / keep in memory. the tokens may include system prompt , user prompt , reterival context and output generation.

Maximum amount of tokens which model can consider at one time, it keep hold in memory.

Context window is container for maximum no of tokens which it can hold

Input tokens : which user sends to LLm
Output tokens: which LLm generates to the user

Large Context Window : Large Processing , Reasoning, multi chat conversation and also Enterprise RAG
Small Context Window : No Large Processing and Reasoning General Purpose .
