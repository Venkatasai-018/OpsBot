Temperature: Temperature defines the randomness of model o/p

Lower Temperature -> Fact based , Determestic and focused

Higher Temperature-> Creative, diversed and more ways/random

Temperature   UseCase

0.0           Normal Factual , Determenstic , straight from book

0.1 -0.4      RAG , chatbot, Search

0.4 -0.7      Assistant 

0.8- 1.0      Creative  content

1.0 <         More Creative content 


Maximum Tokens : Maximum amount of tokens which model used to generate the output.

the amount of tokens which model can generate the o/p

for example 

max_tokens=10 

it will generate the o/p upto 10 tokens


Temperature --> How to write the o/p
Max_Tokens --> How much to write the o/p



Stopping sequence : A word / Symbol which AI stops writing the o/p when it appears.
