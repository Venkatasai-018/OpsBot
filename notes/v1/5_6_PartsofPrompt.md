6 Parts of Prompt

ROLE : who the model should be

TASK : what should it do

CONTEXT : Background information

RULES/Constrains/Instructions : What Rules / constrains / limitaions will be there

O/P Format : Desired Format/Structure 

Examples : To understand the patterns


Best prompt by using above parts

<ROLE>you are a senior devops engineer</ROLE>

<Task>you need to explain kubernetes concepts </Task>

<Context> I already some basic concepts like pods,deployment..etc </Context>

<Rules>Just give me high level overview not more than 10 lines each and simple explanation needed</Rules>

<o/p>I need o/p in this format for every concept
1] definition
2] concept simple understanding
3] examples
<o/p>

<Examples>
1]Pod: Pod is smallest unit of kubernetes
2] pod is ephemral
3] poda podb etc..
</Examples>
