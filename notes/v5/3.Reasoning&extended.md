Reasoning Model:

A model which is specially designed for reasoning ,or finetuned mainly based on reasoning

it breaks the complex task in smaller one

1] Plan before answer
2] validate the assumptions
3] check assumptions
4] handle multi-step validations
5] reduce the mistakes

Que-> reason->validate->answer

ExtendedThinking:

Giving model to think before answer and take some time to answer,to get best o/p

Que->Reasoning->more doublechecks->Answer

Extended thinking will have disadvantage consume more tokens and latency in generation
