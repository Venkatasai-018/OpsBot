Prompt Chaining

Prompt chaining is one best techique , in which a large task is divided into smaller prompts where output of one task will be input for next task.

First Identify the Problem and sends to releated/Specilized Prompt

step1->step2->step3->finalo/p

it acheives maintainability,reusuability,accuracy and reliablity

Pattern1: Sequential chain

Pattern follows sequentially 

flow :

P1->p2-p3->final o/p

Pattern2: Parallel Chain

Pattern follows parallely where one output can be taken by many 


flow: P1->o/p->p3&p2
      
      P2

Pattern3: RouterChaning
Here a main router prompt will identify the best subprompt for the problem and sends to there

eg: HelpDeskBot

If problem comes releated to HR-->it sends to HRdesk prompt
if problem comes releated to ITDesk-> it sends to ITDesk Prompt

Pattern4: Eval & Optimizerchain
OneLLM Generates,another reviews and another improves
Flow: 

Generator-->Draft-->Evalutor-->Feedback-->Optimize
