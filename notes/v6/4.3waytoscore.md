3 methods which LLm gets Score

1] Exact Match

Matching Result Exactly and give pass/fail

for example prompt a->comparsion result 90% of 100%

Mainly used for classification,structured o/p


2] Human Screening 

Humans will screen the o/p generated by LLM

eg Summarize the article
accuracy 1-5
concise 1-5
complete 1-5
clear 1-5

3] Pair Wise Comparsion (A/B)

compare 2 prompts versions directly

Prompt A vs Prompt B
Llm Decides which give result better on each test case
