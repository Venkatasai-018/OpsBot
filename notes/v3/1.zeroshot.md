Zero Shot Prompting

Zero shot prompting is prompt engineering techinque which we doesnt provide any examples in the prompt examples are usually in the input and output format .

Zero Shot Prompting is used for smaller tasks like classification, facts checking ,summarization,translation, code explanantion

Zero Shot prompt is mainly uses the llm pretrained data / patterns to perform a task . it doesnt have any exteranl examples

Eg: Translate "Hi how are to " french
