FewShot Prompting

Fewshot prompt is prompt engineering techinque in which we will provide some set of examples in the prompt as input and output pair , it will analyze the pattern of examples before generating the response, which improves the accuracy and consistency

FewShot Prompting mainly used in custom classification, Ticketing , labelling, sentiment analysis ..etc

Fewshot prompting eg / template pattern

<instructions></instructions>

<example-1><output-1>
<example-2><output-2>
<example-3><output-3>

<New input>

This examples will teach the model in which what task to perfom , O/p format and also style of pattern
